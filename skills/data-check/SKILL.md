---
name: data-check
description: 데이터 파일을 처음 받았을 때, 또는 새 데이터가 추가됐을 때 품질 점검을 하고 reports/data_check.md를 쓸 때 사용
---
1. 먼저 동봉 스크립트를 돌린다(표준 라이브러리만 사용, 수 초):
   `python3 scripts/data_check.py data/ --out reports/data_check.md [--target 타깃컬럼]`
   → 파일별 행·열, 타입, 결측률, 고유값, 범위·극단값, 날짜 범위, 중복 행, 키 중복, 타깃 분포, 파일 간 키 정합성, 누수 의심 컬럼이 표로 나온다.
2. 스크립트가 못 보는 것을 보탠다: 단위 혼재, 샘플링 주기, 학습/평가 분포 차이, 과제 설명과 다른 컬럼 의미.
3. 리포트의 "확인 필요" 체크박스를 하나씩 보고 판단을 적는다. "문서와 대조" 표를 과제 문서·메신저의 숫자로 채운다. 다르면 멈추고 보고한다.
4. 처리 결정(결측·이상치·중복)을 리포트 끝과 NOTES.md에 이유와 함께 한 줄씩 적는다.
5. 사용자에게 4줄 보고: 했다 / 확인했다 / 확인 못 했다 / 다음.

출력 예(요약 표):
| 파일 | 행 | 열 | 중복 행 | 인코딩 | 비고 |
|---|---|---|---|---|---|
| sensor_log.csv | 2,415 | 6 | 15 | utf-8-sig | |

확인 필요 예:
- [ ] sensor_log.csv: 중복 행 15건 → 제거할지, 정당한 중복인지
- [ ] sensor_log.csv.temp_c: 극단값 12건 (IQR×3 밖) → 단위 오류인지 실제 이상인지 원본 확인
