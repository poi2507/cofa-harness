name: baseline
description: 분석·모델링 시작 시 검증 분할과 베이스라인을 만들고 첫 재현 가능한 결과를 낼 때 사용
---
1. 검증 설계부터: 시간 컬럼 → 시간 분할, 그룹 → 그룹 분할, 아니면 K-fold. 테스트는 마지막 1회. 근거를 NOTES.md에 쓴다.
2. 지표 확정: 과제 지표가 있으면 그것, 없으면 유형에 맞게 고르고 이유를 기록한다.
3. 베이스라인 순서: 상수(평균/최빈) → 단순 규칙 → 선형/로지스틱 → 트리(있으면). 점수를 EXPERIMENTS.md에 남긴다.
4. 결과를 outputs/에 저장하고 src/baseline.py + run.sh로 재현되게 한다.
5. 오류 사례 5건을 뽑아 패턴을 적는다. 다음 개선 후보 3개를 제시하고 멈춘다.
