1. NOTES.md·EXPERIMENTS.md·VERIFICATION.md를 읽고 QA_PREP.md에 예상 질문 10개와 답을 쓴다(답마다 3문장, 숫자 포함).
2. 반드시 포함: 문제 정의 이유 / 데이터 문제와 처리 / 지표·방법 선택 이유와 대안 / 검증 방법 / AI가 틀린 사례와 발견 방법 / 가장 큰 가정 / 시간이 더 있다면 / 한계와 리스크 / 핵심 코드 설명 / 현업 적용 조건.
3. 코드의 핵심 3곳을 파일·줄 범위로 지목하고 한 문장씩 설명한다.
4. 사용자가 설명하기 어려운 항목을 표시하고 더 쉬운 표현을 제안한다.
