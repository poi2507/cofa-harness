---
name: dashboard
description: 분석 결과를 HTML 대시보드나 간단한 웹 화면으로 보여줘야 할 때 사용
---
1. 사용자와 먼저 정한다: 누가 어떤 결정을 위해 보나, 꼭 볼 숫자 3개.
2. outputs/dashboard.html 단일 파일. 데이터는 JSON으로 인라인, 차트는 inline SVG 또는 순수 JS. 외부 CDN·폰트 금지.
3. 구성: 상단 핵심 지표 3개 → 비교/추세 차트 → 상세 표 → 각 숫자의 계산 근거 각주.
4. 생성 스크립트 src/build_dashboard.py로 재현한다. 브라우저 미리보기로 확인하고 깨진 곳을 보고한다.
5. 꾸미기는 마지막. 축 스케일·단위·라벨 정확성이 우선이다.
