---
name: llm-pipeline
description: 텍스트·로그 같은 비정형 데이터를 LLM API로 분류·추출·요약하는 파이프라인을 만들 때 사용
---
1. 키는 환경변수에서만 읽는다. 코드·로그에 넣지 않는다. 호출 전에 키 존재를 확인한다.
2. 라벨·추출 스키마를 먼저 JSON으로 정의한다. 프롬프트는 prompts/v1.md부터 버전으로 관리한다.
3. 먼저 키워드 규칙 베이스라인을 만들어 비교 대상으로 둔다.
4. 20~30건 샘플에 사용자가 정답을 매긴 뒤 정확도를 측정해 VERIFICATION.md에 쓴다. 기준에 못 미치면 프롬프트 v2.
5. 전체 실행: 캐시(JSON, 입력 해시 키), 실패 재시도 상한, 타임아웃, 진행 로그, 호출 수 기록.
6. 결과 집계와 오류 유형 5건을 리포트에 넣는다.
