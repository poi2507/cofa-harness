# 유형 프로필: 이상 탐지 (센서·시계열)
공통 규칙 위에 추가로 따른다. 충돌하면 공통 규칙이 우선.

## 시작 시 추가 질문
- 정상 구간의 정의(라벨 또는 기간) / 오탐 허용 수준(하루 몇 건까지) / 이상의 종류(급변·드리프트·결측)

## 필수 산출물 (T+105까지)
1. 데이터 프로파일: 센서·설비별 샘플링 주기, 단위, 결측 패턴 → reports/data_check.md에 포함
2. 정상 범위 정의: 규칙(이동평균 ± k·σ, 분위수, 또는 중앙값·MAD) + k 선택 근거
3. 탐지 결과 표: 시각, 대상, 값, 기준, 심각도 → outputs/anomalies.csv
4. 라벨이 있으면 재현율·정밀도·오탐 수. 없으면 상위 10건 수동 검토 결과
5. 이상 구간을 표시한 시계열 차트(inline SVG, 설비 1~3개)

## 규칙
- 결측은 0으로 채우지 않는다. 결측 자체를 이상 후보로 다룬다.
- 기준 통계는 이상이 섞이지 않은 구간으로 잡거나 중앙값·MAD처럼 강건한 통계를 쓴다.
- 규칙 기반이 먼저다. 모델(Isolation Forest 등)은 규칙과 비교할 때만 쓴다.
- 임계값을 바꿀 때마다 탐지 건수 변화를 EXPERIMENTS.md에 적는다.

## 검증
- 탐지된 상위 5건을 원본 데이터에서 직접 확인한다.
- 임계값을 ±20% 바꿔도 핵심 결론이 유지되는지 본다.
