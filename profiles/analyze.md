# 유형 프로필: 원인 분석·인사이트
공통 규칙 위에 추가로 따른다. 충돌하면 공통 규칙이 우선.

## 시작 시 추가 질문
- 기준 기간과 비교 기간 / 성공 기준(얼마나 개선되면 성공인지) / 이미 알려진 원인, 제외할 원인

## 필수 산출물 (T+105까지)
1. 지표 정의서: 이름, 계산식, 분자·분모, 단위, 기간 → reports/metric.md
2. 세그먼트 비교표: 설비·라인·제품·시간대 등 가능한 축마다 지표 + 표본 수 → outputs/segments.csv
3. 기여도 분해: 전체 변화량 중 각 세그먼트가 차지하는 몫
4. 상위 원인 3개: 각각 근거 표 1개 + 반증 시도 1개(다른 축으로 봐도 유지되는지)
5. 제안 1~3개: 예상 효과(숫자와 계산 방법), 비용·리스크, 확인 방법

## 분석 규칙
- 비율을 비교하기 전에 분모가 같은지 확인한다. 표본 30 미만 세그먼트는 결론에서 빼거나 표시한다.
- 합친 결과와 세그먼트별 결과가 반대면(심슨의 역설) 반드시 보고한다.
- 상관은 "관련 있음"으로만 쓴다. 원인이라고 쓰려면 시간 순서·메커니즘·반증 시도를 적는다.
- 이상치 제거 전후로 결론이 바뀌는지 확인한다.

## 검증
- 핵심 지표 1개를 다른 방법(수동 집계 또는 다른 코드)으로 재계산한다.
- 세그먼트 합계가 전체와 같은지 확인한다.

## 보고서 순서
결론(원인 3개 + 제안) → 지표 정의 → 근거 → 반증 시도 → 한계
