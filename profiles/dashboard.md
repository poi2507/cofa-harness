# 유형 프로필: 의사결정 도구·대시보드
공통 규칙 위에 추가로 따른다. 충돌하면 공통 규칙이 우선.

## 시작 시 추가 질문
- 사용자(누가) / 결정(무엇을 바꾸나) / 꼭 봐야 할 숫자 3개 / 갱신 주기 / 필터 축

## 필수 산출물 (T+105까지)
1. 지표 정의서 3~5개(계산식·단위·출처)
2. outputs/dashboard.html 단일 파일: 상단 핵심 지표 → 추세·비교 차트 → 상세 표 → 각주(계산 근거)
3. src/build_dashboard.py: 데이터 → JSON 인라인 → HTML 생성. run.sh에 포함
4. README에 "이 화면으로 내리는 결정" 한 문단

## 도구
- 먼저 `python3 scripts/eda_report.py`로 그래프 후보를 뽑고, 그중 결론을 뒷받침하는 2~4개만 대시보드에 옮긴다. eda_report.py의 SVG 함수(histogram·bars·lines·heat)를 재사용해도 된다.

## 규칙
- 외부 CDN·폰트·이미지 금지. inline SVG + 순수 JS.
- 차트마다 제목에 결론, 축에 단위, 0부터 시작(아니면 표시).
- 필터는 최대 2개. 인터랙션보다 숫자 정확성이 우선.
- 꾸미기는 T+150 이후에만.

## 검증
- 화면의 숫자 3개를 원본에서 재계산해 일치를 확인한다 → VERIFICATION.md
- 브라우저 미리보기에서 콘솔 에러 0, 창 폭을 줄여도 깨지지 않음.
